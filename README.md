# 💝 Personal Mother's Day Gift Website

A personalized web project designed to celebrate Mother's Day by sharing heartfelt gifts, messages, and memories.  
This site allows you to create a unique digital space for your mom, combining love, creativity, and technology.

---

## 🌸 Features
- **Personalized Gift Showcase**: Upload and display custom gifts (photos, videos, or handmade items).
- **Message Wall**: Share heartfelt notes, quotes, and dedications.
- **Memory Gallery**: Curated collection of family photos and special moments.


---

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP (XAMPP/Apache)
- **Hosting**: Vercel
